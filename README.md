# Portfolio Next Steps

The post-masterclass guide for "Build Your AI-Powered Portfolio": what to add to the portfolio after class,
real example portfolios, a domain × AI project picker, eight upgrades with prompts, a checklist,
and the Interview Kickstart call to action.

- `index.html` is the whole site: one static page, no build step, no dependencies.
- `guide.md` is the same content as plain Markdown.

## Run it locally

Open `index.html` in a browser.

https://avrawat-ik.github.io/portfolio-next-steps/
