# Portfolio Next Steps

The post-masterclass guide for "Build Your AI-Powered Portfolio": what to add to the portfolio after class,
real example portfolios, a domain × AI project picker, eight upgrades with prompts, a checklist,
and the Interview Kickstart call to action.

- `index.html` is the whole site: one static page, no build step, no dependencies.
- `guide.md` is the same content as plain Markdown.

## Run it locally

Open `index.html` in a browser.

## Deploy

Static hosting only. On Vercel: import this repository, framework preset "Other", no build command,
output directory `.` (the repository root).

## Before sharing

- The "Get your customized roadmap" buttons point to `https://interviewkickstart.com` as a placeholder.
  Replace every occurrence with the program advisor booking link.
- Job-description figures come from Interview Kickstart's analysis in `pm_rawat/data/jd/history/`.
